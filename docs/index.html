Q-Learning öneri

Bir puan tablosu. Satırlar durumlar (örnek: yorgunluk yüksek, uyku iyi), sütunlar egzersizler. Hücredeki sayı "bu durumda bunu yaparsam ileride ne kadar ödül alırım" demek. Ajan günlerce dener, tabloyu günceller.

Günlük tablo nasıl yapılır?

Tüm dosyaların sıklığı farklı. Çözüm: hepsini "kişi + gün" satırına indir ve yan yana koy. p01 için çıkan çekirdek tablo 152 satır, 18 sütun. Aşağıdaki kod p01 üzerinde çalıştırılıp denendi.

# Dakikalık dosyayı güne toplar (adım, kalori)
def gunluk(dosya):
    df = pd.read_json(f"{P}/fitbit/{dosya}.json")
    df["deger"] = df["value"].astype(float)          # metni sayıya çevir
    df["gun"] = pd.to_datetime(df["dateTime"]).dt.normalize()
    return df.groupby("gun")["deger"].sum()

adim, kalori = gunluk("steps"), gunluk("calories")

# Uyku puanı ve dinlenik nabız (sabah bilinir)
uyku = pd.read_csv(f"{P}/fitbit/sleep_score.csv", parse_dates=["timestamp"])
uyku["gun"] = uyku["timestamp"].dt.tz_localize(None).dt.normalize()
uyku = uyku.groupby("gun")[["overall_score", "resting_heart_rate"]].first()

# Hedef: yorgunluk
w = pd.read_csv(f"{P}/pmsys/wellness.csv", parse_dates=["effective_time_frame"])
w["gun"] = w["effective_time_frame"].dt.tz_localize(None).dt.normalize()
w = w.groupby("gun")[["fatigue"]].mean()

# Antrenman yükü = zorluk × dakika. Antrenman yoksa 0.
s = pd.read_csv(f"{P}/pmsys/srpe.csv", parse_dates=["end_date_time"])
s["gun"] = s["end_date_time"].dt.tz_localize(None).dt.normalize()
s["yuk"] = s["perceived_exertion"] * s["duration_min"]
yuk = s.groupby("gun")["yuk"].sum()

t = pd.DataFrame({"adim": adim, "kalori": kalori,
                  "uyku_puani": uyku["overall_score"],
                  "dinlenik_nabiz": uyku["resting_heart_rate"],
                  "yuk": yuk}).join(w)
t["yuk"] = t["yuk"].fillna(0)

# Çekirdek özellik: günlük çok aktif geçirilen dakika
v = pd.read_json(f"{P}/fitbit/very_active_minutes.json")
v["gun"] = pd.to_datetime(v["dateTime"]).dt.normalize()
t["very_active_minutes"] = v.set_index("gun")["value"].astype(float)
t = t.sort_index()

# Geçmiş sütunları: shift(1) = önceki kayıt, bugünü içermez
# Önce takvim günlerinin eksiksiz/sıralı olduğundan emin ol.
for c in ["adim", "kalori", "yuk", "very_active_minutes"]:
    t[c + "_dun"] = t[c].shift(1)
    t[c + "_7gun_ort"] = t[c].shift(1).rolling(7, min_periods=3).mean()

Yukarıdaki kod tek başına çalışır. Aşağıdaki ekstra blok isteye bağlıdır. Eklersen tablo 18 sütundan 39 sütuna çıkar. Eklemezsen hiçbir şey bozulmaz. İki tabloyu (çekirdek ve ekstralı) ayrı ayrı eğitip doğrulama hatalarını karşılaştırırsan ablation deneyini yapmış olursun.

Ekstra: aday sütunları ekle (isteye bağlı)

# Çekirdek koddan sonra çalıştırılır. Günlük dosyaları okur.
def gunluk_dosya(ad):
    d = pd.read_json(f"{P}/fitbit/{ad}.json")
    d["gun"] = pd.to_datetime(d["dateTime"]).dt.normalize()
    return d.set_index("gun")["value"].astype(float)

# Ekstra üç yoğunluk: orta, hafif aktif ve hareketsiz (çok aktif çekirdekte)
yogunluk = ["moderately_active_minutes", "lightly_active_minutes",
            "sedentary_minutes"]
for ad in yogunluk:
    t[ad] = gunluk_dosya(ad)

# Nabız bölgeleri: iç içe sözlüğü düzleştir
z = pd.read_json(f"{P}/fitbit/time_in_heart_rate_zones.json")
z["gun"] = pd.to_datetime(z["dateTime"]).dt.normalize()
z = pd.DataFrame(z["value"].apply(lambda v: v["valuesInZones"]).tolist(), index=z["gun"])
z.columns = ["nabiz_" + c.lower() for c in z.columns]
t = t.join(z)

# Hepsi için dünün ve son 7 günün değeri (bugünü içermez)
ekstra = yogunluk + list(z.columns)
for c in ekstra:
    t[c + "_dun"] = t[c].shift(1)
    t[c + "_7gun_ort"] = t[c].shift(1).rolling(7, min_periods=3).mean()

# Modele girerken bugünün ham sütunları (adım, kalori, ekstra...) çıkar,
# yalnızca "_dun" ve "_7gun_ort" ile biten sütunları ve sabah değerlerini kullan.

Veri sızıntısını önleyen kurallar

Proje belgesi ve veri açıklaması bu kuralları özellikle istiyor. Sızıntı, modelin test sırasında göremeyeceği bilgiyi eğitimde görmesidir. Sonuçlar olduğundan iyi çıkar ve hocanın ilk bakacağı şey budur.

Kişiye göre bölBir kişinin hiçbir günü hem eğitimde hem testte bulunmasın. 16 kişi: 12 eğitim, 2 doğrulama, 2 test. Günleri rastgele bölme.
Dönüşümleri eğitimden öğrenEksik doldurma, ölçekleme ve özellik seçimi yalnızca eğitim kişileriyle öğrenilir. Doğrulama ve teste sadece uygulanır.

Geçmiş ortalamaları dünden başlasın7 günlük ortalamada bugün dahil olmasın. Kodda shift(1) bunu sağlıyor.
